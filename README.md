# 🐾 PetShop Minac - E-commerce Educacional

Projeto desenvolvido para as práticas de laboratório técnico, com o objetivo de construir um e-commerce funcional para o aprendizado de HTML5, CSS3, manipulação do DOM e consumo de dados.

---

## 🎯 Sobre o Projeto

O **PetShop Minac** simula uma loja virtual real do segmento pet, permitindo que os alunos compreendam a estrutura de uma aplicação web moderna:
* **Cabeçalho funcional:** Busca integrada e acesso rápido ao carrinho.
* **Filtros interativos:** Seleção rápida por categorias para exibir os produtos de forma dinâmica.
* **Vitrine organizada:** Divisão clara entre Destaques da Semana e o Catálogo Geral.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e limpa.
* **CSS3:** Estilização com Flexbox e paleta de cores personalizada.
* **JavaScript:** Lógica de manipulação do DOM e integração com dados.
* **Git & GitHub:** Versionamento e controle de código-fonte.
